NullPointerException

Java Android Kotlin
⬆

245

Upvote

□
Description

NullPointerException occurs when you try to access a member of a null object. It means you are trying to use a variable that has not been initialized or is set to null.

?
Cause
  • Variable not initialized
  • Object is null
  • Missing null check
✓
Solution
  • Check for null before using the variable
  • Initialize the object properly
  • Use conditional checks (if(obj != null))
